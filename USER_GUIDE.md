## Вступ

Система управління заявками сервісного центру - це програмне забезпечення для автоматизації роботи сервісного центру з ремонту техніки. Програма дозволяє:

- Реєструвати заявки на ремонт
- Відстежувати статус виконання робіт
- Вести облік клієнтів та їх пристроїв
- Призначати техніків на виконання робіт
- Вести фінансовий облік вартості ремонтів

---

## Системні вимоги

### Мінімальні вимоги:
- **Операційна система**: Windows 7 SP1 або новіша (Windows 10/11 рекомендується)
- **Платформа**: .NET Framework 4.7.2 або новіша
- **База даних**: SQL Server LocalDB (встановлюється з Visual Studio)
- **Процесор**: Intel Core i3 або еквівалент
- **Оперативна пам'ять**: 2 ГБ
- **Вільне місце на диску**: 100 МБ

### Рекомендовані вимоги:
- **Операційна система**: Windows 10/11
- **Оперативна пам'ять**: 4 ГБ або більше
- **Вільне місце на диску**: 500 МБ

## Встановлення

### Варіант 1: Запуск через Visual Studio

1. Встановіть Visual Studio 2017 або новішу версію
2. Під час встановлення оберіть компоненти:
   - .NET desktop development
   - SQL Server Data Tools
3. Відкрийте файл `WindowsFormsApp2.sln`
4. Натисніть F5 для запуску програми

### Варіант 2: Збірка та запуск виконуваного файлу

1. Відкрийте проект у Visual Studio
2. Оберіть `Build > Build Solution` (або натисніть Ctrl+Shift+B)
3. Перейдіть до папки `WindowsFormsApp2\bin\Debug\`
4. Запустіть файл `WindowsFormsApp2.exe`

### Встановлення SQL Server LocalDB

Якщо LocalDB не встановлено:

1. Завантажте SQL Server LocalDB з офіційного сайту Microsoft
2. Запустіть інсталятор
3. Виберіть стандартні налаштування
4. Перезапустіть комп'ютер після встановлення

## Перший запуск

При першому запуску програма автоматично:

1. Створить базу даних `ServiceCenterDB.mdf` у папці програми
2. Створить всі необхідні таблиці
3. Заповнить базу тестовими даними:
   - 5 клієнтів
   - 4 техніки
   - 7 пристроїв
   - 6 заявок на ремонт

Процес ініціалізації займає 5-10 секунд.

## Робота з головною формою

### Опис елементів

![Головна форма](images/main-form-description.png)

**Верхня панель:**
- Показує назву системи
- Відображає загальну кількість заявок

**Таблиця заявок:**
- Відображає всі заявки в системі
- Сортування за датою прийому (нові зверху)
- Колонки:
  - **№** - номер заявки
  - **Клієнт** - ім'я та прізвище клієнта
  - **Пристрій** - бренд та модель пристрою
  - **Проблема** - опис несправності
  - **Технік** - призначений майстер
  - **Статус** - поточний стан заявки
  - **Дата прийому** - коли заявка створена
  - **Вартість** - орієнтовна вартість ремонту

**Кнопки управління:**
- **Додати заявку** (зелена) - створити нову заявку
- **Оновити** (синя) - оновити дані з бази даних

### Перегляд заявок

1. Після запуску програма автоматично завантажує всі заявки
2. Для оновлення списку натисніть кнопку "Оновити"
3. Для прокрутки використовуйте смуги прокрутки таблиці

## Додавання нової заявки

### Крок 1: Відкриття форми

Натисніть кнопку **"Додати заявку"** на головній формі.

### Крок 2: Заповнення даних

**Обов'язкові поля:**
1. **Клієнт** - оберіть клієнта зі списку
2. **Пристрій** - оберіть пристрій, що потребує ремонту
3. **Технік** - призначте техніка для виконання роботи
4. **Опис проблеми** - детально опишіть несправність

**Додаткові поля:**
1. **Статус** - за замовчуванням "Нова"
2. **Дата прийому** - за замовчуванням поточна дата та час
3. **Орієнтовна вартість** - приблизна вартість ремонту в гривнях
4. **Примітки** - додаткова інформація

### Крок 3: Збереження

1. Перевірте правильність введених даних
2. Натисніть кнопку **"Зберегти"**
3. При успішному збереженні з'явиться повідомлення з номером заявки
4. Форма автоматично закриється
5. Список заявок оновиться

### Крок 4: Скасування

Для відміни створення заявки натисніть кнопку **"Скасувати"**.

### Валідація даних

Програма перевіряє:
- Чи обрано клієнта
- Чи обрано пристрій
- Чи обрано техніка
- Чи заповнено опис проблеми
- Чи коректно введено вартість (якщо вказано)

При помилці з'явиться попереджувальне повідомлення.

## Структура бази даних

### Таблиці

**RepairStatuses** - статуси заявок
- Нова
- В роботі
- Очікування деталей
- Завершено
- Видано клієнту
- Скасовано

**Clients** - інформація про клієнтів
- ID, ім'я, прізвище
- Телефон, email, адреса

**Technicians** - дані про техніків
- ID, ім'я, прізвище
- Спеціалізація, телефон

**DeviceTypes** - типи пристроїв
- Смартфони
- Ноутбуки
- Планшети
- Комп'ютери
- Побутова техніка

**Devices** - конкретні пристрої
- ID, тип, бренд, модель
- Серійний номер

**RepairRequests** - заявки на ремонт
- Всі дані про заявку
- Зв'язки з клієнтом, пристроєм, техніком, статусом

### Розташування бази даних

База даних зберігається у файлі:
```
[Папка програми]\ServiceCenterDB.mdf
```

Для резервного копіювання скопіюйте цей файл та відповідний .ldf файл.

## Усунення неполадок

### Проблема: "Не вдається підключитися до бази даних"

**Рішення:**
1. Переконайтеся, що встановлено SQL Server LocalDB
2. Перевірте, чи не заблоковано файл бази даних іншою програмою
3. Перезапустіть програму з правами адміністратора

### Проблема: "База даних не створюється"

**Рішення:**
1. Перевірте наявність прав на запис у папці програми
2. Вимкніть антивірус тимчасово
3. Запустіть програму від імені адміністратора

### Проблема: "Дані не зберігаються"

**Рішення:**
1. Перевірте з'єднання з базою даних
2. Переконайтеся, що всі обов'язкові поля заповнені
3. Перегляньте повідомлення про помилки

### Проблема: "Програма не запускається"

**Рішення:**
1. Встановіть .NET Framework 4.7.2 або новішу версію
2. Перевірте системні вимоги
3. Перевстановіть програму
