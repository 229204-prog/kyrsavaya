# 🚀 Швидкий старт

## Як запустити проект за 3 кроки

### Крок 1: Підготовка середовища

Переконайтеся, що у вас встановлено:
- ✅ Windows 7 SP1 або новіша (рекомендується Windows 10/11)
- ✅ Visual Studio 2017 або новіша версія
- ✅ SQL Server LocalDB (встановлюється разом з Visual Studio)

### Крок 2: Відкриття проекту

1. Відкрийте Visual Studio
2. Виберіть `File → Open → Project/Solution`
3. Знайдіть та відкрийте файл `WindowsFormsApp2.sln`

### Крок 3: Запуск

1. Натисніть **F5** або кнопку **Start** (зелена стрілка)
2. Дочекайтеся компіляції проекту
3. Програма запуститься автоматично!

---

## ✨ Що відбудеться при першому запуску?

При першому запуску програма автоматично:
1. 📦 Створить базу даних `ServiceCenterDB.mdf`
2. 🗄️ Створить всі необхідні таблиці
3. 📊 Заповнить базу тестовими даними
4. 🖥️ Відкриє головне вікно з даними

---

## 📱 Перші дії в програмі

### Перегляд заявок
Після запуску ви побачите:
- Список із **6 тестових заявок** на ремонт
- Інформацію про клієнтів, пристрої, техніків
- Статуси виконання робіт

### Додавання нової заявки
1. Натисніть зелену кнопку **"Додати заявку"**
2. Заповніть форму:
   - Оберіть клієнта
   - Оберіть пристрій
   - Оберіть техніка
   - Опишіть проблему
3. Натисніть **"Зберегти"**
4. Нова заявка з'явиться в списку!

### Оновлення даних
Натисніть синю кнопку **"Оновити"** для перезавантаження даних з бази.

## ❓ Що робити, якщо...

### Програма не компілюється?
✔️ Переконайтеся, що встановлено .NET Framework 4.7.2 SDK

### База даних не створюється?
✔️ Перевірте, чи встановлено SQL Server LocalDB  
✔️ Запустіть Visual Studio від імені адміністратора

### Помилка "LocalDB not found"?
✔️ Встановіть SQL Server LocalDB:
   - Запустіть Visual Studio Installer
   - Оберіть "Modify"
   - Додайте "SQL Server Data Tools"
